# DA.MA. — Agenzia immobiliare

Sito multipagina per DA.MA. Servizi Immobiliari, ispirato al mockup fornito.

## Avvio locale

Apri `index.html` nel browser oppure esegui un server statico, ad esempio:

```bash
npx serve .
```

Le pagine sono `index.html`, `immobili.html`, `vendi.html`, `chi-siamo.html` e `contatti.html`.

## Nota sui contenuti

Recapiti, indirizzo e annunci sono dati dimostrativi da sostituire con quelli reali dell'agenzia. I moduli mostrano una conferma nel browser e richiedono un backend per l'invio effettivo.
